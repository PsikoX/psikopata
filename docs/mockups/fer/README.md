# Estudos visuais FER

Abrir `index.html` para comparar três propostas. A direção B inclui um protótipo de movimento em três quadros, sem JavaScript, com versão estática para quem prefere movimento reduzido. Estes ficheiros são estudos de direção visual e não alteram a página `/fer/`.

- **A, Manuscrito:** topologia de três vértices e um centro observada no [Scutum Fidei medieval](https://commons.wikimedia.org/wiki/File:PetrusPictaviensis_CottonFaustinaBVII-folio42v_ScutumFidei_early13thc.jpg).
- **B, Basalto:** colunas naturais de seis lados da [Hexagon Pool](https://en.wikipedia.org/wiki/Hexagon_Pool) como base material; a formação de um triângulo FER é uma invenção visual, não uma estrutura existente no local.
- **C, Entrelaçado:** três arcos da [triquetra em arte medieval](https://en.wikipedia.org/wiki/Triquetra) traduzidos para uma peça material.

O [Magen David](https://en.wikipedia.org/wiki/Star_of_David) é um hexagrama formado por dois triângulos e um símbolo de identidade judaica. Foi estudado como referência geométrica e histórica, mas não aplicado como logótipo de FER nestes estudos.

As imagens dos mockups foram geradas para explorar a direção artística. As fontes históricas e geológicas estão indicadas separadamente; nenhuma imagem gerada é apresentada como fotografia de um artefacto real.
